# 🚗 PakWheels Used Cars Dataset (20,000+ Entries)

This repository contains a comprehensive dataset of **20,000+ used cars** listed on [PakWheels.com](https://www.pakwheels.com/), one of Pakistan's largest automobile marketplaces. The dataset spans across **40 car categories**, making it a valuable resource for data analysis, machine learning, pricing prediction, trend analysis, and more.

---

## 📦 Dataset Overview

- **Total Entries**: ~20,000
- **Categories**: 40 (e.g., SUVs, Sedans, 660cc Cars, Automatic Cars, etc.)
- **Source**: [PakWheels.com](https://www.pakwheels.com/)
- **Scraped Using**: `BeautifulSoup` and `requests` in Python
- **Format**: CSV (`car_listings.csv`)

---

## 📑 Features Included

| Column         | Description                                     |
|----------------|-------------------------------------------------|
| `category`     | Car category (e.g., Family Cars, 660cc Cars)    |
| `title`        | Full listing title                              |
| `price`        | Listed price (PKR)                              |
| `city`         | City where the car is listed                    |
| `year`         | Year of manufacture                             |
| `mileage`      | Total kilometers driven                         |
| `fuel`         | Type of fuel (e.g., Petrol, Diesel, Hybrid)     |
| `engine`       | Engine capacity (e.g., 1300 cc)                 |
| `transmission` | Transmission type (Automatic/Manual)            |
| `url`          | Link to the full listing on PakWheels           |
